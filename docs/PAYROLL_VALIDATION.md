# Validation Engine

Modular pure rules in `validation-engine.ts`:

- DUPLICATE_EMPLOYEE, NEGATIVE_PAYROLL, MISSING_COMPONENT
- SALARY_BELOW/ABOVE min/max, INVALID_BPJS/TAX
- INACTIVE_EMPLOYEE, DUPLICATE_COMPONENT, PAYROLL_BUDGET_EXCEEDED
- MISSING_APPROVAL, NO_EMPLOYEES, FORMULA_ERROR

Severity: INFO | WARNING | ERROR | BLOCKER

API: `GET/POST /api/payroll/validate`
